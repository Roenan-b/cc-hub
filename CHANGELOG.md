## 0.2.0

### Features

- Lead and worker Claude Code sessions in tmux, connected through Claude Code channels.
- Postgres message history with full-text search, a task board with dependencies and role enforcement, and approvals.
- Git worktree per engineer; Obsidian vault with autocommit and private-remote sync.
- Watchdog: stall, dialog, and usage-limit detection, lead check-ins, daily reports, recovery after sleep or power-off.
- Admin and observer dashboards for browser and phone.
- One-command setup for Windows (WSL2) and Ubuntu / Debian, with autostart.

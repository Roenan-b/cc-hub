# Getting help

- **Setup problems:** start with [docs/SETUP-WINDOWS.md](docs/SETUP-WINDOWS.md) or [docs/SETUP-LINUX.md](docs/SETUP-LINUX.md), then search [existing issues](https://github.com/Roenan-b/cc-hub/issues).
- **Bugs:** open a [bug report](https://github.com/Roenan-b/cc-hub/issues/new?template=bug_report.yml) with your OS, Claude Code version (`claude --version`), and the relevant lines of `hub.log`. Remove tokens first.
- **Ideas:** open a [feature request](https://github.com/Roenan-b/cc-hub/issues/new?template=feature_request.yml) or check the [roadmap](docs/ROADMAP.md).
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).
